# AI Engineer Roadmap Tracker

Personal tracker for my AI Engineer learning roadmap (2026), adjusted for an existing Python developer background. Companion repo: algorithmspatterns (DSA + System Design interview prep).

## Phase 0: Interview Fundamentals (ongoing, parallel track)
- [ ] Data Structures & Algorithms patterns - tracked in the algorithmspatterns repo
- [ ] System Design fundamentals and practice problems - tracked in the algorithmspatterns repo
- [ ] Behavioral / core skills prep (communication, past project stories, STAR method)
- Resource: NeetCode.io, "System Design Interview" by Alex Xu, ByteByteGo YouTube, Gaurav Sen YouTube

## Phase 1: Data Skills
- [ ] NumPy: arrays, broadcasting, vectorized ops
- [ ] Pandas: dataframes, groupby, merging, cleaning messy data
- [ ] Data visualization: Matplotlib, Seaborn, basic dashboarding
- [ ] SQL: joins, window functions, aggregations, query optimization basics
- [ ] Exploratory Data Analysis (EDA) workflow end-to-end
- Resource: codebasics Pandas/SQL playlists, freeCodeCamp data analysis courses

## Phase 2: Math & Stats for AI
- [ ] Linear algebra: vectors, matrices, dot products, eigenvalues/eigenvectors
- [ ] Calculus basics: derivatives, gradients, chain rule
- [ ] Probability: distributions, Bayes' theorem, conditional probability
- [ ] Statistics: mean/variance, hypothesis testing, confidence intervals, p-values
- [ ] Maximum likelihood estimation
- Resource: 3Blue1Brown "Essence of Linear Algebra" and "Essence of Calculus", StatQuest stats/probability series

## Phase 3: Core Machine Learning
- [ ] Linear & logistic regression
- [ ] Decision trees, random forests, gradient boosting (XGBoost/LightGBM)
- [ ] Support Vector Machines
- [ ] K-Nearest Neighbors, Naive Bayes
- [ ] Unsupervised learning: K-Means, hierarchical clustering, DBSCAN
- [ ] Dimensionality reduction: PCA, t-SNE
- [ ] Model evaluation: cross-validation, precision/recall/F1, ROC-AUC
- [ ] Overfitting/underfitting, regularization (L1/L2)
- [ ] Feature engineering and feature selection
- [ ] Hyperparameter tuning (grid search, random search, Bayesian optimization)
- Resource: StatQuest (algorithm-by-algorithm), freeCodeCamp "Machine Learning for Everybody"

## Phase 4: ML Projects
- [ ] Project 1: Customer churn prediction (classification)
- [ ] Project 2: House/price prediction (regression)
- [ ] Project 3: Text or image classifier
- [ ] Project 4: End-to-end pipeline with proper train/test/validation split and reproducibility
- Resource: Kaggle datasets and competitions

## Phase 5: Deep Learning
- [ ] Neural network fundamentals: perceptron, activation functions
- [ ] Forward and backward propagation from scratch
- [ ] Optimizers: SGD, momentum, Adam
- [ ] Regularization for deep nets: dropout, batch norm
- [ ] CNNs: convolutions, pooling, classic architectures
- [ ] RNNs/LSTMs/GRUs basics (for sequence data)
- [ ] Transformers: attention mechanism, encoder/decoder architecture
- [ ] Framework practice: PyTorch or TensorFlow
- Resource: 3Blue1Brown neural network series, Andrej Karpathy "Neural Networks: Zero to Hero"

## Phase 6: Specialization (choose NLP or Computer Vision, or both)
- [ ] NLP: tokenization, embeddings, text classification, named entity recognition
- [ ] NLP: fine-tuning pretrained transformer models (e.g., BERT)
- [ ] Computer Vision: image classification, object detection, segmentation basics
- [ ] Computer Vision: transfer learning with pretrained CNNs
- Resource: freeCodeCamp / codebasics specialization playlists

## Phase 7: Generative AI & Agentic AI
- [ ] LLM fundamentals: tokenization, context windows, sampling strategies
- [ ] Prompt engineering techniques
- [ ] Retrieval-Augmented Generation (RAG): embeddings, vector databases, chunking strategies
- [ ] Fine-tuning vs. prompting vs. RAG tradeoffs
- [ ] Building AI agents: tool use, planning, multi-step reasoning
- [ ] Agent frameworks (e.g., LangChain, LlamaIndex, or similar)
- Resource: Andrej Karpathy "Deep Dive into LLMs", freeCodeCamp Agentic AI course

## Phase 8: MLOps & Deployment
- [ ] Building REST APIs for models with FastAPI
- [ ] Containerization with Docker
- [ ] Model versioning and experiment tracking (e.g., MLflow)
- [ ] CI/CD basics for ML projects
- [ ] Deploying to a cloud free tier (Azure or AWS)
- [ ] Monitoring deployed models (latency, drift, basic logging)
- Resource: freeCodeCamp FastAPI/Docker crash courses

## Phase 9: Capstone Project
- [ ] Design an original end-to-end AI/ML project combining multiple phases above
- [ ] Build, train, and evaluate the model
- [ ] Deploy it (API + simple frontend or demo)
- [ ] Document the project thoroughly on GitHub as a portfolio piece
- [ ] Write a short case-study/blog post explaining design decisions
